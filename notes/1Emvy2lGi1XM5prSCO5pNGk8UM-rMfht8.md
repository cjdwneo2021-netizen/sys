# NLP_전처리단계설계_및_DTM직접구성_윤태은_2021011984.xlsx의 사본

### NLP 전처리 및 DTM 구성 학습

이 실습은 텍스트 데이터를 전처리하고 문서-단어 행렬(DTM)을 직접 설계하는 과정을 다룹니다 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-1:row-1].

#### 1. 전처리 단계 설계 상세
| 단계 | 단계 이름 | 적용 규칙/설명 | 이유 |
| :--- | :--- | :--- | :--- |
| Step 1 | Lowercase | 모든 문자를 소문자로 통일 | Data/data의 중복 분리 방지 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-3:row-6] |
| Step 2 | Punctuation removal | 문장부호 제거, 공백 정리 | 같은 단어를 일관되게 비교 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-3:row-7] |
| Step 3 | 형태 단순화 | 데이터를→데이터, 분석은→분석 | 같은 개념 통합 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-5:row-8] |
| Step 4 | 기본형 정리 | 찾는다→찾다, 만든다→만들다 | 변형어 통합 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-5:row-9] |
| Step 5 | 최종 토큰 확정 | 핵심 의미 중심으로 토큰 정리 | DTM용 변수 추출 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-5:row-10] |

#### 2. DTM(Document-Term Matrix) 예시 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-5:row-20]
| 문서 ID | 데이터 | 분석 | 모델 | 좋다 | 텍스트 | ... |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| K1 | 1.0 | 1.0 | 0.0 | 0.0 | 0.0 | ... |
| K5 | 1.0 | 0.0 | 1.0 | 2.0 | 0.0 | ... |

#### 3. AI 보충 설명
- DTM 구성 시 단어 빈도 0.0은 해당 문서에 특정 단어가 포함되지 않았음을 의미합니다 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-5:row-23].
- 전처리 단계(불용어 제거, 표제어화 등)는 분석의 어휘 공간(vocabulary) 크기를 결정합니다 [SOURCE 1Emvy2lGi1XM5prSCO5pNGk8UM-rMfht8:sheet-2:row-30].
